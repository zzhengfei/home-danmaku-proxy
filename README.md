# 家庭弹幕代理（HomeDanmakuProxy）

一个跑在家庭局域网里的小型服务，给电视/机顶盒上的影视播放器补充弹幕。

> **说明**：本仓库是项目说明页。程序为个人自用工具，源码不公开。

---

## 这个项目解决什么问题

家里用电视盒子看片，播放器自带的弹幕只认自己平台的内容。一旦片子来自别的数据源（影视聚合接口），弹幕就全空了——明明是很热门的番剧，画面上一条弹幕都没有。

这个工具的做法是：在家庭局域网的一台常开电脑上跑一个小服务，播放器请求弹幕时先问它，它按片名和集数去弹幕库做匹配，取回弹幕再吐给播放器。

## 工作方式

```
电视播放器
   │  POST /danmaku  { 片名, 集数 }
   ▼
家庭弹幕代理（本机 Node.js 服务）
   │  1. 片名清洗（去字幕组标签、副标题、季集标记、标点）
   │  2. 集数归一（"第216集" / "EP216" / "216" → 216）
   │  3. 走弹幕库搜索接口拿节目编号
   │  4. 按节目编号取弹幕，转成播放器认识的 XML
   │  5. 本地缓存 6 小时
   ▼
返回弹幕文件地址 → 播放器加载
```

## 特性

- **只读**：仅调用搜索与获取弹幕两个公开接口，不发送弹幕、不写任何数据
- **本地缓存**：搜索结果与弹幕 XML 缓存 6 小时，同一集重复观看不重复请求上游
- **按优先级兜底**：多个弹幕来源按优先级依次询问，前面命中就不打扰后面
- **失败不阻断**：任何来源出错只记一行日志，不影响播放本身
- **零依赖**：单文件 Node.js 实现，不需要数据库、不需要容器

## 部署环境

| 项 | 要求 |
|---|---|
| 运行环境 | Node.js 18+（用到内置 fetch） |
| 网络 | 家庭局域网，不需要公网 IP |
| 端口 | 一个本地端口，供局域网内播放器访问 |
| 常驻 | 一台常开的电脑或小主机 |

## 数据来源

弹幕数据接入 **弹弹play 开放弹幕网络**（[www.dandanplay.com](https://www.dandanplay.com/)）。

- 仅使用其公开接口：`/api/v2/search/episodes`、`/api/v2/comment/{episodeId}`
- 鉴权使用开发者中心分配的 AppId / AppSecret，凭证只保存在本机
- 遵守其《第三方开发者接入 API 的使用约定》
- 本工具不收费、无广告，弹幕功能对使用者完全免费

## 使用场景

- 个人家庭观影
- 局域网内 1–3 台设备
- 日均请求量 20 次以内

不对外提供服务，不存在多用户注册、不涉及任何商业化行为。

## 常见问题

**Q：为什么不做成公开可用的在线服务？**
A：弹弹play 的接口约定里明确不鼓励把弹幕能力做成对外服务，这个工具定位就是家庭自用，所以只在自己家里跑。

**Q：会收集用户数据吗？**
A：不收集。服务只处理播放器传来的片名和集数，日志留在本机内存里，重启即清空。

**Q：匹配不上怎么办？**
A：片名差异（繁体、副标题、季数标注）是最常见原因。程序里有名称清洗，但仍有覆盖不到的情况；后续计划加本地别名表。
